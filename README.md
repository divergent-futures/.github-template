                                      ## The problem

                                      Two or three sentences on what's actually wrong with how this is normally done.
                                      This is the part people remember, and it's what makes the rest worth reading.

                                      ## What this does about it

                                      The approach, and the one or two decisions that are genuinely unusual. Not a
                                      feature list -- the *thinking*. If someone else could steal one idea from this
                                      project, name it here.

                                      ## Status

                                      Where it really is. What works, what doesn't, what's untested.

                                      Be specific: "the electrical subsystem is documented, the thermal loop is
                                      modelled but not validated, nothing has been built" beats "early stage".

                                      If numbers in the docs are estimates rather than measurements, **say so here**,
                                      not in a footnote.
